PROJECT_001
FILE ORGANIZER

A 1,000+ line desktop application that automatically sorts files into categorized folders, detects duplicates by SHA-256 content hash, and provides a full session-persistent undo system — all through a modern GUI.

  • SHA-256 duplicate detection — identifies identical files by content, not just filename, with an interactive resolution dialog
  • Full undo system — every operation persisted to JSON history, fully reversible even after the app restarts
  • Decoupled engine/GUI architecture — core logic works as a standalone importable Python library
  • Auto-categorizes into Images, Documents, Videos, Audio & more; works on any user-selected directory
